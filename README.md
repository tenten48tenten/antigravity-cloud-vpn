# 🌐 Ücretsiz Bulut Masaüstü ve Google Chrome (Engelsiz İnternet)

Bu depo, GitHub Codespaces üzerinde ücretsiz masaüstü ve Google Chrome çalıştırmak için hazırlanmıştır.

## 🚀 Tek Tıkla Başlat

Aşağıdaki bağlantıya tıklayarak bulut bilgisayarınızı başlatabilirsiniz:

👉 **[Bulut Bilgisayarı Başlat (Codespaces)](https://github.com/codespaces/new?hide_repo_select=true&ref=main&repo=tenten48tenten/antigravity-cloud-vpn)**

---

## 💻 Nasıl Kullanılır?

1. Yukarıdaki bağlantıya tıklayın ve **"Create codespace"** (Yeşil buton) seçeneğine basın.
2. İlk kurulum yaklaşık **2-3 dakika** sürer (arka planda masaüstü ve Google Chrome kurulur).
3. Kurulum bitince alt kısımdaki **PORTS (Bağlantı Noktaları)** sekmesine tıklayın.
4. **6080 (Bulut Masaustu)** portunun yanındaki **🌐 Dünya (Tarayıcıda Aç)** simgesine tıklayın.
5. Şifre sorarsa: **`admin`** yazıp giriş yapın.
6. Karşınıza engelsiz, yüksek hızlı Google Chrome ekranı gelecektir!
